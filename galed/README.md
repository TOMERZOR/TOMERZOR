# גלעד · Galed

אפליקציה למציאת שותפים למסלול: קטע בשביל ישראל, מסלול יום בגליל או טרק בחו״ל. מפרסמים לאן ומתי, מוצאים מי הולך באותו קטע, ומתאמים בצ׳אט.

**השם:** גַּלְעֵד הוא גל אבנים שהקימו יעקב ולבן כעדות לברית ביניהם (בראשית ל״א). עד היום, ערמת אבנים (cairn) בצד השביל מסמנת את הדרך. באפליקציה, כל יציאה משותפת מוסיפה אבן לגלעד שלך.

## הרצה

```bash
cd galed
npm install
npm run dev      # http://localhost:5173
npm run build    # בדיקת טיפוסים + בנייה ל-dist/
```

בלי הגדרות, האפליקציה רצה **במצב הדגמה**: נתונים לדוגמה שנשמרים בדפדפן, ותשובות מדומות (מארגנת שמאשרת בקשה, מישהו שמבקש להצטרף ליציאה שפרסמת, תשובות בצ׳אט). React 18, TypeScript, Vite, Framer Motion.

## חיבור לשרת (Supabase)

כשמגדירים פרויקט Supabase, האפליקציה עוברת **למצב אמיתי**: הרשמה במייל, פרופילים, יציאות, בקשות הצטרפות וצ׳אט בין משתמשים, עם עדכונים בזמן אמת.

1. פותחים פרויקט חינמי ב-[supabase.com](https://supabase.com).
2. ב-SQL Editor מריצים את כל הקובץ `supabase/migrations/0001_init.sql`.
3. ב-Authentication → URL Configuration מוסיפים את כתובת האתר (למשל `http://localhost:5173` ואת כתובת האתר המפורסם) ל-Redirect URLs. משם חוזרים מקישור הכניסה במייל.
4. מעתיקים את `.env.example` ל-`.env.local` וממלאים את `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` מ-Project Settings → API.
5. `npm run dev`. מסך הפתיחה יוביל לכניסה במייל ואז להשלמת פרופיל.

לפרסום: כל אירוח סטטי (Vercel, Netlify, Cloudflare Pages) עם `npm run build`, אותם שני משתני סביבה, ותיקיית `dist`.

### אבטחה

כל טבלה מוגנת ב-Row Level Security. בקצרה:
- רק משתמשים מחוברים רואים משהו. מבקר אנונימי לא רואה כלום.
- כל אחד עורך רק את הפרופיל, היציאות וההודעות שלו. את התג "מאומת" אפשר לתת רק מצד השרת.
- טלפון של איש קשר לחירום נשמר בטבלה נפרדת שרק הבעלים רואים.
- בקשה ממתינה גלויה רק למבקש ולמארגן. רשימת המאושרים גלויה לכולם.
- אי אפשר לאשר מעבר למספר המקומות, ואי אפשר לבקש להצטרף ליציאה של עצמך.
- שיחה נפתחת רק דרך הפונקציה `start_thread`, ותמיד מול מארגן היציאה. אי אפשר להכניס אדם זר לשיחה.

### בדיקות

```bash
npm run test:db    # מריץ את המיגרציה ובדיקות הרשאות על Postgres 16 מקומי
npm run test:api   # מריץ את src/backend/live.ts מול PostgREST אמיתי: פרופיל, פרסום, בקשה, אישור, צ׳אט
```

`test:db` צריך Postgres 16 מותקן (`/usr/lib/postgresql/16/bin`, או `PG_BIN`). `test:api` צריך גם את [PostgREST](https://postgrest.org) (ב-PATH או ב-`POSTGREST`). עדכונים בזמן אמת (Realtime) לא נבדקים מקומית. צריך לבדוק אותם מול פרויקט Supabase אמיתי.

## שפת העיצוב

- **נייר ומפה:** רקע נייר חם, קווי גובה (קונטורים) שמצוירים באנימציה, קצה עמוד קרוע כמו מפה.
- **שתי דיו של ריזוגרף:** כחול אולטרמרין וכתום פלואורסצנטי, אותם צבעים של סימון שביל ישראל. כותרות עם "הזזת הדפסה" קלה בין שתי השכבות.
- **סימוני שבילים:** שלושת הפסים (לבן-צבע-לבן) כפי שהם צבועים על סלעים בארץ, עם שוליים "מרוחים".
- **כרטיסים ככרטיסי נסיעה:** תלוש תאריך עם ניקוב, חותמת התאמה מסובבת, צל קשיח במקום צל מטושטש.
- **טיפוגרפיה:** Frank Ruhl Libre לכותרות, IBM Plex Sans Hebrew לממשק, IBM Plex Mono לכל מספר (ק״מ, עלייה, קואורדינטות, שעות).
- **מצב לילה בשטח:** דיו כחולה כהה במקום נייר.
- **תנועה:** אבני הגלעד נופלות ומתייצבות בקפיץ, קווי גובה ופרופיל גובה נמתחים, חותמת "פורסם" ננחתת על הכרטיס, כפתורים נלחצים כמו חותמת. מכבדים `prefers-reduced-motion`.

הטוקנים (צבעים, גופנים, צללים) נמצאים בראש `src/styles.css`.
