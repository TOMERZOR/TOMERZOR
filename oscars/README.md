# האוסקרים של הפלגה: סרטון התוצאות

סרטון מושן של כ־10.5 דקות (‏1920×1080, ‏30fps) שחושף את תוצאות טופס "האוסקרים" בסגנון טקס: פתיחה עם וילונות וזרקורים, ולכל אחת מ־14 הקטגוריות כרטיס כותרת עם עולם גרפי משלה, ספירה לאחור 3, 2, 1, מקום שלישי ושני, תיפוף, הזוכה עם פסלונים וקונפטי, ובסוף כל התשובות בגרף. בשאלות הטקסט מקבלים במקום זה את המועמדים אחד אחד, והנושא שהוזכר הכי הרבה זוכה. בין הקטגוריות יש הפסקות של תמונות מהפלגה, ובסוף פרס "מפעל חיים" ומסך סיום.

## פרטיות
הריפו ציבורי. **שום דבר אישי לא נמצא בו**: התשובות לטופס, התמונות, הפנים, הקריינות, הסאונד והסרטון עצמו יושבים ב־`private/`, שנמצאת ב־`.gitignore`. גם שם הפלגה, הקרדיט, הסלוגן ובחירת התמונות נמצאים שם, ב־`private/config.json`. בריפו יש רק את המנוע: הקוד, הפונטים (SIL OFL) והאייקונים (Fluent Emoji, רישיון MIT).

מה צריך להיות ב־`private/`: ‏`votes.csv` (הייצוא מגוגל פורמס), ‏`config.json`, ‏`photos/`, ‏`faces/<שם>.jpg` (פנים חתוכות, אחת לכל אחד) ו־`audio/wav/` (אפקטים וקריינות).

## הקבצים
- `build-data.py`: קורא את ה־CSV מגוגל פורמס, מאחד כתיבים שונים ("אהרון בנהרוש" ← אהרון, "אורין ויסמין" נספר לשתיהן), סופר קולות, בונה פודיום (תיקו חולק מדרגה) ומקבץ תשובות טקסט לפי מי שהן עליו. הפלט הוא `private/data.json`.
- `index.html` + `engine.js` + `scenes.js`: הסרטון כולו. כל פריים הוא פונקציה טהורה של הזמן (`render(t)`). ציר הזמן נבנה מהנתונים, כל סצנה מתחילה על פעמה (120 BPM), וכל צליל רשום על הפריים שלו.
- `render.mjs`: מצלם את הפריימים עם Playwright בכמה דפדפנים במקביל ומחבר אותם עם ffmpeg. הוא גם כותב את `sfx.json` (רשימת הצלילים) ואת `marks.json` (חלקי המוזיקה).
- `audio.py`: הפסקול. המוזיקה מסונתזת (אלקטרו־פופ ב־120 BPM, לה מינור). היא נבנית בפתיחה, מתהדקת בכל ספירה לאחור, כמעט נעלמת בתיפוף ומתפוצצת בזוכה, ויורדת מתחת לקריין. האפקטים והקריין נוצרו ב־ElevenLabs.
- `shots.mjs`: צילומי מסך של רגעים נבחרים לבדיקה מהירה, בלי רינדור מלא.
- `build.sh`: הכל מהתחלה עד הסוף. מוציא גרסת 1080p וגרסה קלה ב־720p לוואטסאפ.

## לבנות מחדש
```
npm install                 # פונטים ואייקונים
pip install numpy scipy
./build.sh                  # private/out/oscars-1080p.mp4 + oscars-720p.mp4
```
לתצוגה מקדימה בדפדפן: `python3 -m http.server 8811` ואז לפתוח `http://127.0.0.1:8811/` (מתנגן בלופ בלי סאונד; `?t=120` מציג פריים אחד, `?from=120` מתחיל משם).

## לשנות
- טקסטים, צבעים ופונט לכל קטגוריה: `THEMES` בראש `scenes.js`.
- אורך וזמני קריאה: מחושבים לפי אורך הטקסט ב־`resultsScene` / `textScene`.
- תמונות להפסקות: `breaks` ב־`buildTimeline`.
