# קולי (Koli)

קולי לומדת איך יוצר/ת תוכן כותב/ת, ועונה לעוקבים בהודעות הפרטיות באינסטגרם בקול שלו/ה. היא מזהה על איזה קמפיין שואלים (לפי הסטורי שהגיבו אליו, המילים בהודעה וההקשר של השיחה), עונה רק מהעובדות שהיוצר/ת כתב/ה, נותנת קוד קופון ולינק עם תיוג למעקב מכירות, ומעבירה ליוצר/ת את מה שצריך מגע אישי.

זה פיילוט שעובד: אפשר לנסות אותו מיד, ולחבר אותו לאינסטגרם דרך ה-API הרשמי של Meta.

## מה יש בפנים

| | מה זה עושה |
|---|---|
| **הקול** | ייבוא של קובץ "הורדת המידע שלך" מאינסטגרם (ZIP או JSON): ההודעות שהיוצר/ת שלח/ה, כיתובים ותגובות. כל הודעה של עוקב/ת שקיבלה תשובה נשמרת כזוג "שאלה ותשובה". אפשר גם להדביק טקסט. Claude מנתח את הדוגמאות לפרופיל קול (ביטויים, סלנג, אימוג׳ים, אורך, פתיחות וסגירות) שאפשר לערוך. הקובץ נקרא בדפדפן בלבד. |
| **מבחן הקול** | 10 הודעות שעוקבים באמת שולחים (מחיר, מחמאה, ביקורת, "את באמת משתמשת בזה?", בקשה להיפגש, עוקבת שנעלבה, נושא רגיש ועוד), כל אחת בודקת מצב אחר. היוצר/ת עונה כמו בפרטי, והתשובות הן הדוגמאות שקולי סומכת עליהן הכי הרבה: הן נכנסות ראשונות להנחיות ולניתוח הקול. השאלות מנוסחות לפי המגדר של היוצר/ת. |
| **אופי** | שמונה כיוונונים (חום, הומור, אימוג׳ים, אורך, רשמיות, סלנג, אנרגיה, מכירתיות), פנייה בלשון זכר, נקבה או רבים, נושאים להימנע מהם, מתי להעביר ליוצר/ת, כללים חופשיים, ושקיפות: הסימון "העוזרת הדיגיטלית של..." נוסף בקוד ולא תלוי במודל. |
| **קמפיינים** | מוצר, מחיר, קופון, לינק, תאריכים, מילות מפתח, עובדות, שאלות נפוצות, והסטוריז של הקמפיין (עם Story ID מאינסטגרם, אם יש). |
| **תיבת הודעות** | סימולטור: כותבים כמו עוקב/ת, גם כתגובה לסטורי, ורואים את התשובה עם הקמפיין שזוהה, הכוונה, רמת הביטחון וסימון "צריך אותך". במצב טיוטות מאשרים כל תשובה; כל עריכה או "תיקון" נשמרים כדוגמה, והם הדוגמאות שקולי מחקה קודם. |
| **חיבור לאינסטגרם** | שרת (Cloudflare Worker) שמקבל את ה-webhook של Meta, עונה או שומר טיוטה, ומזהה כשהיוצר/ת עונה בעצמו/ה מהאפליקציה ואז מפסיק לענות באותה שיחה ל-12 שעות. |

## לנסות

**ב-claude.ai, בלי התקנה.** הגרסה שפורסמה כ-artifact משתמשת ב-Claude של מי שפותח אותה, דרך יכולת `sample`. מספיק כדי לבנות קול ולנסות תשובות, לא כדי לענות באינסטגרם.

**במחשב, עם מפתח API:**

```sh
cd koli/server && npm install && cd ..
ANTHROPIC_API_KEY=sk-ant-... node tools/serve.mjs
# http://localhost:8787
```

בהרצה מקומית אין צורך בקוד גישה. הבדיקות: `cd koli/server && npm test`.

## להעלות לאוויר ולחבר לאינסטגרם

1. **השרת.** ב-GitHub מוסיפים את הסודות `ANTHROPIC_API_KEY`, `CLOUDFLARE_API_TOKEN` ו-`KOLI_ADMIN_TOKEN` (מחרוזת אקראית ארוכה) ומריצים את ה-workflow ‏**Deploy Koli API**. הוא יוצר אחסון KV לשיחות ומדפיס את כתובת השרת. אפשר גם ידנית: `npx wrangler deploy` בתיקייה `koli/server` ו-`npx wrangler secret put` לכל סוד (ראו `wrangler.toml`).
2. **האפליקציה.** בלשונית "חיבור לאינסטגרם" מזינים את כתובת השרת ואת קוד הגישה, ולוחצים "שליחת ההגדרות לשרת". עושים את זה שוב אחרי כל שינוי בקול, באופי או בקמפיינים.
3. **Meta.** ב-developers.facebook.com יוצרים אפליקציה מסוג Business עם Instagram ("API setup with Instagram login"), מחברים חשבון Creator או Business, ומייצרים token עם `instagram_business_basic` ו-`instagram_business_manage_messages`.
4. **הסודות של אינסטגרם** בשרת (או ב-GitHub, ואז מריצים שוב את ה-workflow): `IG_APP_SECRET` (App settings ← Basic), `IG_ACCESS_TOKEN`, `IG_VERIFY_TOKEN` (מחרוזת שתבחרו).
5. **Webhook.** בהגדרות ה-Webhooks של האפליקציה ב-Meta: כתובת `https://<השרת>/webhook/instagram`, אותו `IG_VERIFY_TOKEN`, ורישום לשדה `messages`.
6. **באפליקציית אינסטגרם:** הגדרות ← הודעות ← כלים מחוברים ← לאפשר גישה להודעות.
7. **App Review.** כל עוד האפליקציה של Meta במצב פיתוח, היא עונה רק לחשבונות שהוגדרו כבודקים. כדי לענות לכל העוקבים צריך לעבור את ה-App Review של Meta עם הרשאת ההודעות. זה הצעד הארוך (בדרך כלל ימים עד שבועות) ודורש מדיניות פרטיות וסרטון הדגמה.

### כללי Meta שקולי עומדת בהם

- תשובה אוטומטית רק בתוך 24 שעות מההודעה של העוקב/ת. קולי עונה רק להודעות נכנסות, אז זה תמיד מתקיים.
- דרך להגיע לבן אדם: "מתי להעביר אלייך", טיוטות, והשהיה אוטומטית כשהיוצר/ת עונה בעצמו/ה.
- בלי התחברות עם סיסמה ובלי אוטומציה של האפליקציה, שמפרות את תנאי השימוש ומסכנות את החשבון.

## איך זה בנוי

```
koli/
  index.html, css/, js/       האפליקציה (HTML ו-JavaScript בלי build)
    js/engine.js              Claude דרך השרת, או דרך ה-artifact ב-claude.ai
    js/views/                 המסכים
  core/                       משותף לדפדפן ולשרת, כך שהסימולטור עונה בדיוק כמו אינסטגרם
    prompt.js                 ההנחיות ל-Claude: קול, כיוונונים, קמפיינים, כללים, ומבנה התשובה (JSON)
    context.js                זיהוי הקמפיין: סטורי, מילות מפתח (כולל תחיליות בעברית), המשכיות השיחה
    reply.js                  הודעה נכנסת ← זיהוי ← Claude ← בדיקת התשובה ← סימון AI
    igexport.js, zip.js       קריאת קובץ המידע של אינסטגרם, כולל תיקון העברית המשובשת שבו
  server/                     Cloudflare Worker: webhook, תיבת הודעות, טיוטות, למידה מאישורים
  tools/serve.mjs             הרצה מקומית של האפליקציה והשרת יחד
```

**המודל.** `claude-opus-5-5` במאמץ `low`, כי אלה תשובות צ'אט קצרות ומהירות. ניתוח הקול רץ במאמץ `medium`. משנים ב-`KOLI_MODEL` ו-`KOLI_EFFORT` ב-`wrangler.toml`. התשובות חוזרות כ-JSON לפי סכמה (structured outputs). ההנחיות הקבועות של היוצר/ת נשמרות ב-prompt cache, כי הן זהות לכל העוקבים. אם Claude מסרב לבקשה, היא עוברת אוטומטית למודל גיבוי (`fallbacks: "default"`).

**עלות משוערת.** כמה אלפי טוקנים של הנחיות (רובם מהמטמון) ותשובה קצרה. בערך סנט עד שניים להודעה; כדאי למדוד על תעבורה אמיתית ולהגדיר תקרת הוצאה ב-console.anthropic.com.

## מה עוד חסר לפני מוצר

- **כמה יוצרים בשרת אחד.** היום שרת אחד משרת חשבון אחד. למוצר: חשבון לכל יוצר/ת, התחברות עם Instagram Login במקום הדבקת token, ואחסון Durable Object לכל יוצר/ת.
- **מכירות.** הלינקים מתויגים ב-UTM (`utm_campaign=koli_<קמפיין>`), אבל ספירת רכישות דורשת חיבור לחנות (למשל Shopify) או לדוחות של המותג.
- **תמונות וקול.** הודעות שהן רק תמונה, סטיקר או הקלטה לא נענות כרגע.
- **ייעוץ משפטי.** פרטיות (הודעות של עוקבים עוברות ל-Claude), גילוי נאות על AI ופרסום של מוצרים. כדאי שעורך/ת דין יעבור/תעבור על זה לפני השקה.
