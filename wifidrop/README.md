# WiFiDrop

שליחת קבצים, תמונות, סרטונים, טקסט וקישורים בין מחשב (Windows, Mac או Linux) לאייפון שנמצאים על אותה רשת Wi-Fi. זה עובד כמו AirDrop, ולא צריך להתקין שום דבר על האייפון.

- **מהאייפון למחשב:** בוחרים תמונות או קבצים ב-Safari, או משתפים מכל אפליקציה דרך קיצור דרך (מפורט בהמשך). הקבצים נשמרים ב-`Downloads/WiFiDrop` במחשב.
- **מהמחשב לאייפון:** גוררים קבצים לדף של WiFiDrop במחשב (או מדביקים צילום מסך עם Ctrl+V), והם מופיעים מיד באייפון להורדה.
- **טקסט וקישורים:** בשני הכיוונים, עם כפתור העתקה.
- הקבצים עוברים ישירות ברשת הביתית. שום דבר לא עולה לאינטרנט, ואין הגבלה על גודל הקובץ.

## למה לא AirDrop אמיתי?

AirDrop של אפל עובד בפרוטוקול סגור (AWDL), שמשתמש בכרטיס ה-Wi-Fi בצורה שמחשבי Windows לא תומכים בה, ואפל לא מאפשרת לאפליקציות אחרות להופיע בחלון של AirDrop. לכן WiFiDrop משתמש במה שכבר יש לשני המכשירים: רשת ה-Wi-Fi ו-Safari. אם מוסיפים את קיצור הדרך, "שליחה למחשב" מופיע בתפריט השיתוף של האייפון ממש ליד AirDrop.

## התקנה והפעלה במחשב

צריך Python 3.8 ומעלה. לא צריך להתקין שום חבילה נוספת.

**הדרך הקצרה (בכל מחשב שיש בו Python):** פותחים Python (החלון עם `>>>`), מדביקים את השורה הזאת ולוחצים Enter:
```python
import urllib.request as u; exec(u.urlopen("https://raw.githubusercontent.com/TOMERZOR/TOMERZOR/claude/nifty-noether-y5yku0/wifidrop/install.py").read())
```
השורה מורידה רק את הקבצים של WiFiDrop לתיקייה `WiFiDrop-app` בתיקיית המשתמש, ומפעילה את התוכנה. בפעמים הבאות מפעילים בלחיצה כפולה על `start-windows.bat` שבתיקייה הזאת.

**Windows**
1. מתקינים Python מ-[python.org/downloads](https://www.python.org/downloads/). בהתקנה מסמנים **Add python.exe to PATH**.
2. לוחצים לחיצה כפולה על `start-windows.bat`.
3. בפעם הראשונה Windows שואל אם לאפשר גישה ברשת. מסמנים **רשתות פרטיות** ולוחצים **אפשר גישה**. בלי זה האייפון לא יצליח להתחבר.

**Mac**: לוחצים לחיצה כפולה על `start-mac.command`. אם macOS חוסם את הקובץ, לוחצים עליו עם הכפתור הימני ← פתח. בפעם הראשונה macOS שואל אם לאפשר חיבורים נכנסים, ועונים **אפשר**.

**מהטרמינל** (בכל מערכת):
```bash
python3 wifidrop.py
```

נפתח דף בדפדפן של המחשב עם קוד QR. צריך להשאיר את חלון הטרמינל פתוח כל עוד משתמשים בתוכנה.

## חיבור האייפון

1. מוודאים שהאייפון מחובר לאותה רשת Wi-Fi כמו המחשב.
2. פותחים את המצלמה, מכוונים לקוד ה-QR שבמחשב ונוגעים בקישור שמופיע.
3. כדאי להוסיף את הדף למסך הבית: ב-Safari נוגעים בכפתור השיתוף ← **הוספה למסך הבית**. מעכשיו WiFiDrop נפתח כמו אפליקציה.

הקישור כולל מפתח גישה אקראי (`?k=...`), כך שרק מי שסרק את הקוד יכול לשלוח ולהוריד קבצים. המפתח נשמר בין הפעלות, אז הקישור במסך הבית ימשיך לעבוד. אם רוצים לנתק את כל המכשירים שהתחברו, מריצים `python3 wifidrop.py --new-key`.

### שמירת תמונות מהמחשב באלבום התמונות

- **תמונה:** נוגעים בתמונה הקטנה כדי לפתוח אותה, לוחצים עליה לחיצה ארוכה ← **שמירה בתמונות**.
- **כל קובץ אחר:** "הורדה" שומר אותו באפליקציית **קבצים**, בתיקייה "הורדות". משם אפשר לשתף אותו לכל מקום (כולל "שמירת וידאו").

## "שליחה למחשב" מתפריט השיתוף (קיצור דרך)

מהרגע שיש את קיצור הדרך, בכל אפליקציה (תמונות, קבצים, WhatsApp ועוד) נוגעים ב**שיתוף** ← **שליחה למחשב**, והקבצים מגיעים למחשב באיכות המקורית. בבחירה דרך Safari, iOS לפעמים ממיר תמונות HEIC ל-JPEG, וקיצור הדרך שולח את הקובץ המקורי.

בונים את קיצור הדרך פעם אחת באפליקציית **קיצורים** (Shortcuts):

1. נוגעים ב-**+** כדי ליצור קיצור דרך חדש, וקוראים לו "שליחה למחשב".
2. נוגעים ב-ⓘ (או בחץ ליד השם) ומפעילים **הצגה בגיליון השיתוף**. בסוגי הקלט בוחרים **תמונות**, **מדיה** ו**קבצים**.
3. מוסיפים את הפעולה **חזור עם כל אחד** (Repeat with Each) על **קלט קיצור הדרך**.
4. בתוך הלולאה מוסיפים **קבל תוכן של URL** (Get Contents of URL):
   - **URL**: הכתובת שמופיעה במחשב, ובמקום `/?k=` כותבים `/api/upload?k=`. מוסיפים בסוף `&name=` ואחריו את המשתנים **פריט חוזר ← שם**, נקודה ו**פריט חוזר ← סיומת קובץ**. לדוגמה:
     `http://192.168.1.20:8765/api/upload?k=המפתח-שלכם&name=[שם].[סיומת]`
   - **שיטה**: POST
   - **גוף הבקשה**: קובץ ← **פריט חוזר**
5. אחרי הלולאה מוסיפים **הצג הודעה** עם הטקסט "נשלח למחשב".

**טקסט מהלוח למחשב:** קיצור דרך נוסף עם **קבל לוח** ואחריו **קבל תוכן של URL** לכתובת `.../api/text?k=המפתח`, שיטה POST, וגוף **קובץ** ← **לוח**. הטקסט מופיע בדף שבמחשב.

**טקסט מהמחשב לאייפון:** **קבל תוכן של URL** מ-`.../api/latest-text?k=המפתח` ואחריו **העתק ללוח**. מקבלים את הטקסט האחרון שנשלח.

## כשמשהו לא עובד

| הבעיה | מה עושים |
| --- | --- |
| האייפון לא מצליח לפתוח את הכתובת | בודקים ששני המכשירים על אותה רשת. ב-Windows בודקים שהרשת מוגדרת כ**פרטית** (הגדרות ← רשת ואינטרנט ← Wi-Fi ← סוג פרופיל רשת) ושההיתר בחומת האש מסומן לרשתות פרטיות. |
| עדיין לא נפתח | בדף שבמחשב לוחצים על "לא נפתח? נסו כתובת אחרת". כשיש VPN או מכונה וירטואלית, המחשב עלול להציג כתובת לא נכונה. רשתות של מלונות ומקומות עבודה לפעמים חוסמות חיבורים בין מכשירים, ובמקרה כזה אפשר להשתמש בנקודה חמה של האייפון. |
| הכתובת השתנתה ביום אחר | הנתב נתן למחשב כתובת חדשה. סורקים שוב, או קובעים למחשב כתובת קבועה בהגדרות הנתב (DHCP reservation). |
| "צריך לסרוק מחדש" | המפתח הוחלף (`--new-key`) או שהקישור נפתח בלי המפתח. סורקים שוב את הקוד. |
| הפורט תפוס | `python3 wifidrop.py --port 8800` |

## אפשרויות

```bash
python3 wifidrop.py --help
```

- `--dir PATH`: התיקייה שבה נשמרים הקבצים שמגיעים מהאייפון. ברירת המחדל היא `~/Downloads/WiFiDrop`. מה שנשלח לאייפון נשמר בתת-תיקייה `To iPhone`, ואפשר גם להעתיק לשם קבצים ישירות מסייר הקבצים.
- `--port N`: הפורט. ברירת המחדל היא 8765.
- `--new-key`: יוצר מפתח גישה חדש.
- `--no-browser`: לא פותח את הדף בדפדפן.
- אם מתקינים את החבילה `qrcode` (`pip install qrcode`), קוד ה-QR מוצג גם בטרמינל.

## מבנה

- `wifidrop.py`: השרת. ספריית התקן של Python בלבד.
- `web/`: הדף, אחד לשני המכשירים. הוא מזהה אם נפתח במחשב עצמו (`localhost`) או באייפון ומציג את המסך המתאים. העדכונים מגיעים בזמן אמת דרך Server-Sent Events.
- `web/vendor/qrcode.js`: [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) של Kazuhiko Arase (רישיון MIT), כדי שקוד ה-QR יעבוד גם בלי אינטרנט.

### API (לקיצורי דרך ולסקריפטים)

בכל בקשה מהאייפון צריך את המפתח: `?k=KEY`, עוגייה או כותרת `X-WiFiDrop-Key`.

| בקשה | מה היא עושה |
| --- | --- |
| `POST /api/upload?name=NAME` | גוף הבקשה הוא הקובץ עצמו. אפשר גם לשלוח את השם בכותרת `X-Filename`. |
| `POST /api/text` | טקסט רגיל, או JSON בצורה `{"text": "..."}`. |
| `GET /api/latest-text` | הטקסט האחרון שנשלח. |
| `GET /api/state` | רשימת הקבצים שממתינים לאייפון והודעות הטקסט. |
| `GET /files/NAME` | הורדת קובץ מהתיקייה `To iPhone` (תומך ב-Range). |
