# ערסלייט

מתרגם עברית תקנית לערסית. כותרת, תיבת טקסט אחת גדולה עם כפתור שליחה עגול, והתרגום נפתח מתחתיה בזמן אמת. כפתורי העתקה, נוסח אחר ושיתוף מופיעים רק כשיש תרגום. רקע תכלת רך, פונט בולד וצפוף (SF במכשירי אפל, Heebo בשאר), ואנימציות חלקות. נראה כמו כלי רציני, וזה בכוונה.

**▶ לפתוח בטלפון או במחשב:** https://tomerzor.github.io/TOMERZOR/arslate/

- `index.html`: האפליקציה (ממשק בהיר, גם במכשירים שמוגדרים למצב כהה).
- `lexicon.js`: המילון, בערך 1,100 מילים וביטויים. כל שורה היא `מילים רגילות = נוסח ערסי | נוסח אחר`.
- `examples.js`: מאגר "הערס החכם", כ-80 משפטים שלמים בעברית רגילה עם הנוסח הערסי שלהם. משמש גם את המילון וגם את מצב ה-AI.
- `engine.js`: מנוע המילון. עובד כולו בדפדפן, בלי שרת ובלי אינטרנט.
- `config.js`: כתובת שרת ה-AI. ריקה = מילון בלבד.
- `worker/`: שרת ה-AI (Cloudflare Worker) ש-Claude מנסח בו מחדש.
- `icons/`, `manifest.webmanifest`: אייקון (חוליית שרשרת זהב) והוספה למסך הבית.

## שני מודלים

בתיבה יש בורר מודלים, כמו בבחירת מודל ב-Claude:
- **ערס 3.5** (ברירת המחדל): אחשלי, יא מלך, באמא שלי, אל תשגע אותי, הצגה...
- **ערסית 2.5**: מדברת בלשון נקבה, עם סלנג משלה: יפה שלי, חיים שלי, מתוקה, לבשלי, שימדורה, מאמי, וואנה, יעני, שרופה על, מחילה, בעזרת השם, ברוך השם, חיה בסרט, שחרר ממני / סעי ממני, אל תעלה לי את העצבים, "אני פיפי, אני מתה" (כשמשהו מצחיק או מוגזם, לא על שירותים).

הבחירה נשמרת בדפדפן. במילון, השורות של ערסית נמצאות באזור `@arsit` ב-`lexicon.js`, והדוגמאות שלה ב-`ARSIT_EXAMPLES` ב-`examples.js`. Claude מקבל את שני הקולות באותה הנחיה, ותגית `<persona>` אומרת לו באיזה מהם לדבר.

## איך זה מתרגם

1. מחפש במילון את הביטוי הארוך ביותר שמתאים (עד 6 מילים), כך ש"אני מאחר קצת" מתורגם כביטוי שלם ולא מילה מילה. מילים עם ו/ש בהתחלה נתפסות, ושמות עצם ותארים גם עם ה/ב/ל/מ/כ ("לעבודה" ← "למשמרת").
2. מוסיף פתיח וסיומת לפי סוג המשפט: שאלה, כעס, אהבה, עצב, התלהבות ("וואלה,", "תקשיב טוב,", "על אמא שלי", "יא מלך").
3. `{A}` במילון הוא מקום לפנייה (אחי, נשמה, כפרה, יא מלך...). לא חוזר על אותה פנייה ולא שם יותר מדי.
4. כשפונים לאישה (את, תגידי, בואי, מאמי...) הפניות והציוויים עוברים ללשון נקבה ("אחותי", "תקשיבי", "כפרה עלייך").
5. אותו טקסט תמיד נותן אותו תרגום. כפתור "נוסח אחר" מגריל נוסח חדש.

## מצב AI

השיטה באה מפודקאסט שבו LSports מספרים איך לימדו מודל שפה "לדבר כמו ערס ולא כמו מורה להיסטוריה": אוספים משפט רגיל ואת הניסוח שלו בשפה הרצויה, והמודל לומד מהזוגות. כאן לא צריך לאמן מודל: הדוגמאות מ-`examples.js` נכנסות להנחיה של Claude, והוא מנסח מחדש כל משפט, כולל מילים שאין במילון.

- השרת: `worker/`. בקשה אחת לכל תרגום (`POST /api/translate`), ההנחיה עם הדוגמאות שמורה במטמון, מגבלה יומית לכל מבקר (60 כברירת מחדל) ומטמון ליום לתרגומים שחוזרים. אם Claude מסרב, הבקשה עוברת אוטומטית למודל גיבוי.
- האתר: כשיש כתובת ב-`config.js`, מתרגמים בלחיצה על שליחה (לא בכל הקלדה, כדי לא לבזבז בקשות). כל תקלה, מגבלה או סירוב נופלים בשקט למילון.
- להפעלה: להוסיף ב-GitHub (Settings ← Secrets and variables ← Actions) את `ANTHROPIC_API_KEY` ואת `CLOUDFLARE_API_TOKEN` (ו-`CLOUDFLARE_ACCOUNT_ID` אם צריך), ולהריץ את "Deploy ArsLate API" מלשונית Actions. הוא פורס את השרת, כותב את הכתובת ל-`config.js` ובונה את האתר מחדש. כדאי להגדיר תקרת הוצאה חודשית ב-console.anthropic.com.
- בדיקות: `cd worker && npm ci && npm test` (עם Claude מדומה, בלי מפתח).

## להוסיף סלנג

משפט שלם: זוג חדש ב-`examples.js` (`["עברית רגילה", "ערסית | נוסח נוסף"]`). הוא מלמד גם את המילון וגם את Claude.

מילה או ביטוי: שורה חדשה ב-`lexicon.js`, באזור המתאים:
- `@phrases`: ביטויים רגילים.
- `@nouns`: שמות עצם ותארים (נתפסים גם עם ה/ב/ל/מ/כ). עדיף נוסח של מילה אחת.
- `@stand`: תשובה שעומדת לבד ("כן", "באמת?").

## מגבלות

בלי שרת ה-AI, המילון מתרגם ביטויים ומשפטים מוכרים: מילים שלא במילון נשארות כמו שהן, ולפעמים יוצא משפט עקום (שזה חלק מהקסם).
