# ערסלייט · Showreel

סרטון הסבר של 50 שניות, 1920×1080, עם קריין, כתוביות מסונכרנות למילה, מושן גרפיקס ופסקול.

## איך זה בנוי

- `index.html`: כל הסרטון כקוד. `render(t)` מצייר כל פריים לפי הזמן, כך שהתוצאה דטרמיניסטית ורנדרת
  פריים-פריים ב־Playwright. כל הקאטים והאנימציות נגזרים מתזמוני המילים של הקריין (`vo.json`), אז מה
  ששומעים הוא מה שזז.
- `vo.mp3`: הקריינות (ElevenLabs, הקול "Nimrod", מודל eleven_v4). `vo.json`: תמלול עם זמני מילים
  (faster-whisper, מודל ivrit-ai) מיושר לתסריט, פלוס `segs`: איפה כל שורה מונחת על ציר הזמן של הסרטון.
- `audio.py`: מסנתז את הפסקול מאפס (דרבוקה במקסום, בס, פד ומלודיה בחיג'אז), מניח את הקריינות, מוריד את
  המוזיקה מתחת לקול (side-chain) ומוסיף אפקטים לפי רשימת הקיוז שהדף מייצר.
- `fonts/`: Heebo מקומי, כדי שהרנדר לא תלוי ברשת.

## לרנדר מחדש

```sh
python3 -m http.server 8793            # מתוך showreel/
node render.js out.mp4                  # פריימים → MP4 (כותב גם sfx.json)
python3 audio.py sfx.json vo.f32 vo.json audio.wav
ffmpeg -i out.mp4 -i audio.wav -c:v copy -c:a aac showreel.mp4
```

התסריט של הקריין נמצא ב־`vo.json` תחת `lines`. כדי לשנות טקסט צריך להקליט מחדש, לתמלל ולהריץ את
`align.py` (בתיקיית העבודה) כדי לעדכן את זמני המילים.
