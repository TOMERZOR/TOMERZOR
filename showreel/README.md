# ערסלייט · Showreel

סרטון הסבר אנכי של 44 שניות, 1080×1920, עם קריין, כתוביות קינטיות על המסך (המילים של הקריין בגדול, מילה-מילה), מושן גרפיקס ואפקטים. בלי מוזיקה.

## איך זה בנוי

- `index.html`: כל הסרטון כקוד. `__seek(t)` מצייר כל פריים לפי הזמן, כך שהתוצאה דטרמיניסטית ורנדרת
  פריים-פריים עם מוטיון בלר אמיתי (render.py של onetake). כל הקאטים והאנימציות נגזרים מתזמוני המילים של
  הקריין (`vo.json`), אז מה ששומעים הוא מה שזז. שני "נשאים" (כרטיס לבן ואריח הלוגו) עוברים מורף מסצנה
  לסצנה, כך שאף ביט לא מוחלף אלא צומח מהקודם. התנועות מ־`motion.js` (ספריית onetake).
- `vo.wav`: הקריינות (ElevenLabs, הקול "Nimrod", מודל eleven_v4, מואץ ב־8%). `vo.json`: תמלול עם זמני מילים
  (faster-whisper, מודל ivrit-ai) מיושר לתסריט, פלוס `segs`: איפה כל שורה מונחת על ציר הזמן של הסרטון.
- `audio.py`: מניח את הקריינות ומסנתז את האפקטים לפי רשימת הקיוז שהדף מייצר. בלי מוזיקה.
- `fonts/`: Heebo מקומי, כדי שהרנדר לא תלוי ברשת.

## לרנדר מחדש

```sh
ffmpeg -i vo.wav -ac 2 -ar 48000 -f f32le vo48.f32
# sfx.json: {sfx: window.__sfx} מהדף (ראו render.js)
python3 audio.py sfx.json vo48.f32 vo.json audio.wav
python3 render.py index.html --out showreel.mp4 --sfx audio.wav --width 1080 --height 1920
```

התסריט של הקריין נמצא ב־`vo.json` תחת `lines`. כדי לשנות טקסט צריך להקליט מחדש, לתמלל ולהריץ את
`align.py` (בתיקיית העבודה) כדי לעדכן את זמני המילים.
