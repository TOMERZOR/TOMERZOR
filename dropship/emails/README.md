# מיילים ללקוחות: הודעות אוטומטיות ומבצעים

שופיפיי שולחת לבד את המיילים החשובים (אישור הזמנה, יציאה למשלוח, תזכורת על סל נטוש). אין צורך לבנות אותם מאפס. צריך רק להגדיר אותם נכון ולהוסיף בלוק אחד שחוסך הרבה פניות "איפה ההזמנה שלי".

## 1. הגדרות בסיס (5 דקות)

1. **Settings ← Languages:** להגדיר עברית כשפה הראשית. אז שופיפיי שולחת את כל ההודעות האוטומטיות בעברית.
2. **Settings ← Notifications ← Customize email templates:**
   - להעלות לוגו (רוחב 120px).
   - צבע הדגשה: `#141A30` (כחול הלילה של האתר). לא הוורוד, כי הכפתורים באתר כחולים.
3. **Settings ← Notifications ← Sender email:** כתובת על הדומיין שלך (למשל `hello@lune.co.il`), ולאמת את הדומיין לפי ההוראות שם. מיילים מכתובת gmail נוטים להגיע לספאם.

## 2. בלוק "מתי זה מגיע" לאישור ההזמנה

הלקוחה קונה מפרסומת ומצפה למשלוח מהיר. אם לא אומרים לה מראש שזה לוקח 10-15 ימי עסקים, היא תכתוב אחרי 5 ימים. הבלוק הזה מוריד חלק גדול מהפניות.

**איך מוסיפים:** Settings ← Notifications ← **Order confirmation** ← Edit code. מחפשים את השורה `{% if requires_shipping and shipping_address %}` (או את תחילת סיכום ההזמנה), ומדביקים מעליה את תוכן הקובץ `order-confirmation-block.html`. שומרים, ושולחים לעצמך מייל בדיקה עם הכפתור Send test email.

## 3. נושאי מיילים (Subject) מומלצים

| הודעה | נושא |
|---|---|
| Order confirmation | `קיבלנו את ההזמנה שלך, {{ name }}` |
| Shipping confirmation | `ההזמנה שלך בדרך, הנה מספר המעקב` |
| Shipping update | `עדכון על המשלוח של הזמנה {{ name }}` |
| Abandoned checkout | `הסט שלך עדיין מחכה בסל` |

`{{ name }}` הוא מספר ההזמנה, ושופיפיי ממלאת אותו לבד.

## 4. תזכורת על סל נטוש

Settings ← Checkout ← **Abandoned checkouts**: להפעיל שליחה אוטומטית אחרי **10 שעות**. כדאי לשלוח רק ללקוחות שסימנו הסכמה לדיוור, כי זה מייל שיווקי ובישראל חל עליו סעיף 30א לחוק התקשורת.

טקסט מומלץ לגוף המייל (Abandoned checkout ← Edit code, במקום משפט הפתיחה):

```
השארת סט LUNÉ בסל. שמרנו לך אותו, ואפשר להשלים את ההזמנה בלחיצה.
משלוח חינם לכל הארץ, וביטול עסקה עד 14 יום מהקבלה.
```

בלי קוד הנחה במייל הראשון. אם רוצים, שולחים תזכורת שנייה אחרי 48 שעות עם `SAVE10` (10% הנחה, מגדירים ב-Discounts).

## 5. מיילים שיווקיים (Shopify Email)

- נשלחים **רק** למי שסימנה הסכמה. התיבה כבר מופיעה בעמוד התשלום של שופיפיי, ובעמוד הסיסמה של התבנית.
- **בכותרת חייבת להופיע המילה "פרסומת"**, למשל: `פרסומת: 2 סטים ב-179 ₪ עד מוצאי שבת`.
- בתחתית: כתובת העסק וקישור הסרה. Shopify Email מוסיף את קישור ההסרה לבד.
- תבנית מוכנה בעיצוב החנות: `marketing-email.html` בתיקייה הזו. מדביקים אותה ב-Shopify Email ← Create campaign ← Custom HTML. אם האפשרות לא זמינה בחשבון שלך, משתמשים בתבנית רגילה עם אותם טקסטים.
