# זכאי – אפליקציית הסבא המדבר

סבא תימני מצויר שעונה על כל שאלה, בקול, בזמן אמת. דף סטטי בלי שלב בנייה.

## הרצה מקומית

```
cd zakai
npx http-server -p 8080 .
```

ואז לפתוח את `http://localhost:8080/app/`. צריך לאשר גישה למיקרופון (ב־localhost או ב־HTTPS בלבד).

- `?demo=speaking` / `?demo=listening` / `?demo=thinking` – מציג את האנימציות בלי חיבור.
- `?agent=agent_…` – מחליף את הסוכן (נשמר בדפדפן).

## איך זה בנוי

| קובץ | מה יש בו |
|---|---|
| `mascot.js` | הדמות ב־SVG, מחולקת לחלקים זזים: מצמוץ, גבות, הטיית ראש, פאות מתנדנדות, ולסת שזזה לפי עוצמת הקול (lip-sync). |
| `app.js` | חיבור WebRTC לסוכן של ElevenLabs, מצבים (מקשיב / חושב / מדבר), כתוביות זורמות, שאלה בכתב. |
| `config.js` | מזהה הסוכן הציבורי. |
| `vendor/` | ספריית `@elevenlabs/client` 1.30.0 (MIT). |
| `../agent/system-prompt.md` | האישיות של זכאי: דיבור, ביטויים תימניים עם מקורות, מה אסור. |
