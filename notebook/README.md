# דפי מחברת להדפסה — כימיה

5 דפים מהמחברת, מועתקים בפונט Tomer Hand ומוצבים על השורות של מחברת Campus A4.

- `notebook-print.pdf` — להדפסה על דפי המחברת (בלי קווים).
- `alignment-test.pdf` — אותו דבר עם הקווים מודפסים, לבדיקה על דף רגיל.

מידות שנמדדו: קו ראשון 29 מ"מ מהקצה העליון, מרווח 70/9 = 7.78 מ"מ (33 שורות), קו שוליים 30 מ"מ מהקצה הימני.

**בהדפסה:** גודל בפועל / 100%, בלי "התאם לדף".

בנייה מחדש: `python3 tools/gen.py DIR` (DIR צריך להכיל את TomerHand-Regular.ttf), ואז `node tools/pdf.js DIR`.
