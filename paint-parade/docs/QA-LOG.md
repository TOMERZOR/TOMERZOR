## סבב 4 — סיור בכל המסכים
חנות, גלריה, הגדרות, ציור יומי, השהיה, כישלון → Revive בסרטון, Grabber, נגמרו הלבבות.
- 🐞 טיימר חבילת הפתיחה הוצג "47h 0:00" → "47h 00m".
- 🐞 בטלפונים גבוהים הלוח היה קטן מדי (4 שורות דליים) → 3 שורות, הלוח גדל.
- 🐞 "coins" באות קטנה בכותרת בחנות → "Coins".
- 🐞 כשאין מספיק מטבעות ל-Revive, החנות נפתחה *מאחורי* חלון הכישלון → נסגר לפני, וחוזרים לחלון הכישלון אחרי החנות.
