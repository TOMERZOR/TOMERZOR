# 🎨 Paint Parade — Color Puzzle

משחק פאזל היברידי-קז'ואל לטלפון. דליי צבע חמודים צועדים על מסוע סביב קנבס אפור ומתיזים את הצבע שלהם על כל פיקסל תואם שהם רואים. בוחרים את הדלי הנכון בזמן הנכון, ממלאים את התמונה, ואוספים 80 יצירות לגלריה.

**למה דווקא המשחק הזה:** המכניקה (יורים צבעוניים על מסוע) היא הז'אנר הכי רווחי של 2025–2026 (Pixel Flow: ‏$100M+ בפחות משנה, צוות של 10 אנשים). הטוויסט שלנו — *לצבוע* במקום להרוס — מוסיף את קהל "צביעה לפי מספרים" (~30M הורדות בחודש) ותגמול רגשי חזק יותר. המחקר המלא: [`docs/RESEARCH.md`](docs/RESEARCH.md).

## מה יש כאן
| נתיב | מה זה |
|---|---|
| `index.html`, `css/`, `js/` | המשחק (HTML5 Canvas + JS, בלי שלב build) |
| `js/engine.js` | חוקי המשחק — סימולציה דטרמיניסטית |
| `js/bot.js` | בוטים שמשחקים דרך אותו מנוע: מאמתים שכל שלב פתיר ומודדים קושי |
| `js/art.js` | 80 ציורי פיקסלים ב-8 אלבומים |
| `js/levelgen.js`, `js/levels.js` | מחולל השלבים ועקומת הקושי |
| `js/levels-data.js` | 200 שלבים מוכנים ומאומתים (נוצר ע"י `tools/build-levels.mjs`) |
| `js/platform.js` | פרסומות (AdMob), רכישות (RevenueCat), רטט, אנליטיקס — מדומים בדפדפן, אמיתיים באפליקציה |
| `app/` | אפליקציית iOS + Android (Capacitor). הוראות: [`app/README.md`](app/README.md) |
| `marketing/` | אייקון, Key art, צילומי מסך לחנויות, טריילר, טקסטים לחנויות (EN), תוכנית השקה |
| `landing/` | דף נחיתה |
| `privacy.html`, `terms.html` | מדיניות פרטיות ותנאי שימוש (חובה לחנויות ול-AdMob) |
| `docs/` | המשימה, מחקר שוק, מסמך עיצוב (GDD), יומן QA |
| `tests/` | בדיקות למנוע (`npm test`) |

## הרצה מקומית
```bash
cd paint-parade
python3 -m http.server 8080      # ואז http://localhost:8080
npm test                         # בדיקות המנוע
node tools/build-levels.mjs 200  # בנייה מחדש ואימות של כל השלבים (~1 דק')
```
פרמטר בדיקה: `?speed=4` מריץ את המשחק פי 4 (לבדיקות אוטומטיות).

## הכלכלה במשחק
- מטבעות: 20 לניצחון (קשה 40, קשה מאוד 60), ‏x2 בצפייה בסרטון. ציור יומי 100 + בונוס רצף.
- בוסטרים: ‎+Spot (150), Grabber (200), Rainbow (250). נפתחים בשלבים 7/12/18 עם 2 במתנה.
- לבבות: 5, אחד מתחדש כל 20 דק', פעילים רק משלב 10 (כדי שהסשן הראשון יהיה בלי חיכוך).
- Revive כשהמקומות מתמלאים: ‎+2 מקומות בסרטון (פעם בשלב) או ב-300 מטבעות.
- פרסומת כפויה רק אחרי ניצחון, רק משלב 12, לכל היותר פעם ב-90 שנ', אף פעם לא אחרי Revive.
- רכישות: Starter $1.99, No Ads $6.99, No Ads Bundle $9.99, חבילות מטבעות $1.99–$49.99.
