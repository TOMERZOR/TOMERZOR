# שכונה ד׳

משחק עולם פתוח בתלת־ממד על החיים בבלוקים של **קריית שמש**, עיירת פיתוח בדיונית בדרום. מצב סיפור של 12 משימות עם נהוראי, ומצב אונליין של שודים עם הכנות לעד ארבעה שחקנים. סאטירה: הדמויות, העסקים והאירועים מומצאים; המצוקה שהם יושבים עליה אמיתית (ראו `design/research.md`).

- **לשחק בדפדפן:** `https://shchuna-d.moffy-app.workers.dev` (פתוח לכולם, כולל האונליין) · עותק ב־Higgsfield: `https://shchuna-d.higgsfield.app` (דורש התחברות ל־Higgsfield)
- **אנדרואיד:** קובץ APK נבנה מ־`app/` (ראו למטה, או את ה־artifact של ה־workflow ״שכונה ד׳ · APK״)
- **להריץ מקומית:** `npx http-server shchuna-d -p 8080` ולפתוח `http://localhost:8080` (אין שלב build)

### הסיפור

נהוראי משתחרר וחוזר לבלוק 412. אמא קיבלה הודעת פינוי כי התחילה לעבוד בשכר מינימום ואיבדה זכאות, ויש חוב של עשרים אלף שתפח למאה ושמונים אלף אצל ז׳וז׳ו מה״צ׳יינג׳״. שלוש מערכות, שני סופים.

1. **חוזרים לבלוק:** שחרור · שליח עד הבית · ריבית דריבית · חלפים משומשים
2. **קומבינות:** דמי חסות · כספומט נייד · מעטפות · זהב ירוק
3. **פינוי־בינוי:** עיר עם עתיד · מלחמת שכונות · המשוריין · שכונה ד׳

### אונליין

פותחים חדר, נותנים לחברים קוד בן ארבע אותיות. המארח בוחר שוד בלוח השודים (בתפריט ההפסקה), הצוות עושה שתי הכנות ואז יוצא לשוד עצמו; הכסף מתחלק שווה. שלושה שודים: **כספומט בצומת**, **המעטפות של ורסאי**, **המשוריין של הבנק**.

מה מסונכרן: השחקנים, הרכבים שהם נוהגים בהם, הדמויות והרכבים של המשימה, היעד, המכות והתשלום. מה לא: הולכי הרגל והתנועה ברקע, שכל שחקן רואה משלו.

## מבנה

```
index.html, css/            המעטפת והממשק
js/engine/                  רינדור, שמיים, קלט, סאונד, פיזיקה, טעינת מודלים ורטרגוט אנימציות
js/world/                   תוכנית העיר (map.js), מחולל הבניינים והרחובות, טקסטורות ושלטים
js/game/                    דמויות, רכבים, אוכלוסייה, משטרה, מנוע משימות, הסיפור, השודים
js/ui/                      HUD, מיני־מפה, תפריטים, טלפון
js/net/online.js            לקוח האונליין
server/                     שרת החדרים (Cloudflare Durable Object), אותו קוד שרץ ב־Higgsfield
app/                        מעטפת Capacitor לאנדרואיד
tools/                      צינור הנכסים, רשימות ה־jobs ב־Higgsfield, דף אייקון
design/                     מחקר הרקע ורשימת הנכסים
```

משימה היא פונקציית `async` שקוראים אותה כמו תסריט (`js/game/story.js`):

```js
await c.talk([['S', 'אחי, יש לי תוכנית…'], ['N', 'שימי, זה כספומט.']], { actors: { S: shimi } });
await c.goto('site', 'לך ל<em>אתר הבנייה</em>');
await c.fight([guard1, guard2], 'הורד את <em>השומרים</em>');
```

## נכסים

הדמויות, הרכבים, האביזרים, הטקסטורות, אמנות המפתח והמוזיקה נוצרו ב־**Higgsfield** (תמונת קונספט ← מודל תלת־ממדי ← שלד ואנימציה). מזהי ה־jobs שמורים ב־`tools/asset-jobs.json` ו־`tools/clip-jobs.json`; קובצי המקור הגולמיים (כ־170MB) לא בריפו. כדי לבנות מחדש את הקבצים המוכנים למשחק:

```bash
cd tools && npm i
node build-assets.mjs        # GLB: טקסטורות WebP, דחיסת meshopt, קליפים בלי mesh
python3 build-textures.py    # אריחים חוזרים + מפות נורמל
```

כל דמות נרגגה בנפרד, אז האנימציות עוברות רטרגוט בזמן הטעינה מתנוחת ה־bind (`js/engine/assets.js`).

## אנדרואיד

```bash
cd app && npm i
npm run apk                  # sync + gradle assembleDebug
# app/android/app/build/outputs/apk/debug/app-debug.apk
```

המשחק כולו ארוז בתוך האפליקציה (מסך מלא, לרוחב, בלי שורת כתובת); מצב הסיפור עובד בלי רשת. ה־APK הוא debug: להפצה בחנות צריך חתימה (`Build → Generate Signed Bundle` ב־Android Studio).

## iOS

```bash
cd app && npm i
npm run ios                  # sync + פותח את ios/App/App.xcodeproj ב־Xcode
```

ב־Xcode: בוחרים את ה־target ״App״ ← Signing & Capabilities ← מסמנים Automatically manage signing ובוחרים Team, מחברים אייפון, בוחרים אותו כיעד ולוחצים Run. המשחק ארוז כולו באפליקציה (לרוחב, מסך מלא). ה־workflow ״שכונה ד׳ · iOS״ בונה ‎.ipa לא חתום, או חותם ומעלה ל־TestFlight אם הוגדרו הסודות שבראש הקובץ.

## שרת האונליין

`server/src/room.ts` הוא ממסר: כל לקוח מדמה את השחקן שלו, החדר מעביר הודעות ושומר את תוכנית השוד. הוא רץ ב־Cloudflare Workers (ה־workflow ״שכונה ד׳ · server״ פורס אותו בכל push) וגם באתר המשחק ב־Higgsfield. להרצה מקומית:

```bash
cd server && npm i && npm run dev      # http://localhost:8787
```

לקוח שרץ מכתובת אחרת (למשל האפליקציה) מתחבר לכתובת שב־`js/net/config.js`; אפשר להחליף עם `?server=wss://…`.

## בדיקות

`tools/` לא כולל את סקריפטי ה־Playwright (הם רצו בסביבת הפיתוח), אבל כל 12 המשימות עברו ריצה אוטומטית מקצה לקצה, וגם תרחיש של שני לקוחות מול שרת מקומי (חדר, תוכנית, דמויות משימה משוקפות, מכות מרחוק).

## מה חסר, בכנות

- אין נשק חם: הקרבות הם ידיים ורגליים בלבד.
- הגלגלים של הרכבים לא מסתובבים (המודלים נוצרו כגוף אחד).
- אין דיבוב: דיאלוגים בכתוביות.
- פנים הבניינים סגור.
- הביצועים נבדקו ברינדור תוכנה בלבד; על טלפון חלש כדאי לבחור איכות ״נמוכה״ בהגדרות.
