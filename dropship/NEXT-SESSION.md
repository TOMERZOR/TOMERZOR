# איך לתת ל-Claude לסיים את הקמת החנות

הסשן הזה לא מצליח להגיע לשופיפיי: הקונקטור צריך התחברות מחדש, והרשת של הסביבה חוסמת את השרתים של שופיפיי. אחרי השלבים כאן, Claude יוכל להקים לבד את רוב החנות.

## מה את/ה עושה (כ-5 דקות)

1. **פתיחת חנות** ב-shopify.com, תוכנית Basic.
2. **חיבור התבנית:** באדמין של שופיפיי, Online Store ← Themes ← Add theme ← Connect from GitHub ← `TOMERZOR/TOMERZOR` ← ענף `lune-theme` ← Publish. או Upload zip עם `lune-theme.zip`.
3. **חיבור מחדש של הקונקטור:** https://claude.ai/customize/connectors ← Shopify ← התחברות לחנות החדשה.
4. **(רשות) פתיחת הרשת**, כדי ש-Claude יוכל גם להעלות שינויים בתבנית בעצמו: הגדרות הסביבה (התפריט בכותרת הסשן) ← Edit ← Network access, ולהוסיף `*.myshopify.com` ו-`accounts.shopify.com` ב-Allowed domains.
5. **לפתוח סשן חדש** (קונקטורים נטענים בתחילת סשן) ולהדביק:

```
החנות של LUNÉ מחוברת. תקרא את dropship/NEXT-SESSION.md ותבצע את כל מה שבסעיף "מה Claude עושה", בלי לעצור, ובסוף תגיד לי מה נשאר.
```

## מה Claude עושה בסשן הבא

1. בודק את החנות (`get-shop-info`): מטבע ILS, שפה ותוכנית.
2. יוצר את המוצר לפי `products.csv`: 9 וריאציות (חבילה × צבע), מחירים, SEO ו-7 תמונות. כתובות התמונות ב-CSV ציבוריות, כך ששופיפיי מעתיקה אותן לבד.
3. מפרסם את המוצר בחנות האונליין ומשנה אותו ל-Active, רק אם כבר מחובר ספק. אחרת הוא נשאר טיוטה.
4. יוצר עמודים: "צור קשר" (תבנית `page.contact`) ו"הצהרת נגישות".
5. בונה תפריטים: `main-menu` (דף הבית, צור קשר) ו-`footer` (צור קשר, הצהרת נגישות).
6. מעדכן את המדיניות מתוך `policies/`, אם פרטי העסק כבר מולאו במקום ה-[סוגריים].
7. יוצר קודי הנחה: `SAVE10` (10%, לתזכורת על סל נטוש) ו-`BLACK15` (15%, תקף 27-30 בנובמבר).
8. מוודא שסקשן "מוצר מוביל" בדף הבית מצביע על המוצר החדש.
9. מדווח מה נשאר לך: סליקה, חשבוניות, דומיין וספק.

## אם אין אפשרות לחבר את הקונקטור: העלאה מהמחשב שלך

אם מותקן במחשב Node.js, מריצים מתיקיית הריפו:

```bash
npx @shopify/cli@latest theme push --path dropship/theme --store YOUR-STORE.myshopify.com --unpublished
```

נפתח דפדפן להתחברות לשופיפיי, והתבנית עולה כתבנית חדשה שעוד לא פורסמה. אחר כך: Online Store ← Themes ← Publish.

ואת המוצר: Products ← Import ← `products.csv`. התמונות נכנסות איתו אוטומטית.
