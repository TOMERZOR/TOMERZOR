# השתול · סבב אחד, טייק אחד

סרטון תדמית אנכי (1080×1920) של כ־41 שניות למשחק [השתול](https://hashtul.onrender.com). הסרטון מציג סבב שלם, מהקוד ועד הכתר, בטייק רציף אחד. מצלמה "מצולמת ביד" רודפת אחרי אצבע שמשחקת.

הקבצים:

- **`hashtul.mp4`**: הסרטון המלא. השאלה של השתול היא "כמה פעמים בשבוע אתם נוגעים בעצמכם?", ומצב פלפל נדלק בלובי.
- **`hashtul-clean.mp4`**: גרסה נקייה לטיקטוק ולרילס, בלי סקס על המסך.
  - השאלה של השתול היא "כמה פעמים בשבוע אתם בודקים מה האקס מעלה?".
  - מצב פלפל נשאר כבוי ("כבוי: שאלות נקיות").
  - חוץ מזה היא זהה לגרסה המלאה, כולל ה־18+ של המשחק.

## המהלך

| זמן (שנ') | מה רואים |
|---|---|
| 0–4 | תקריב על העיניים של החציל, משיכה לאחור, הלוגו נופל אות־אות, "כולם עונים על אותה שאלה. חוץ מאחד." |
| 4–9 | "יש לי קוד": הכפתור נהיה תיבות הקוד, הקוד מוקלד ועף לכרטיס הצהוב, השחקנים נכנסים, מצב פלפל נדלק |
| 9–15 | "סבב 3 מתוך 8": השאלה מחולקת לשחקנים (קלף ורוד אחד ליובל), מקלידים 3, נעלתי |
| 15–20 | "השאלה האמיתית": הכרטיסים מתהפכים: 1, 2, 2, 3, 2... ו־7. "מי פה משקר?" |
| 20–24 | "מי השתול?": בוחרים ביובל, "חשוד!", "הצבעתם" |
| 24–32 | "ההצבעות" ← "השתול הוא..." ← זרקור ← "נתפס!" ← "השאלה של יובל הייתה..." ← ‎+100 |
| 32–36 | "ומי לוקח?": פודיום, כתר וקונפטי. "הכתר של שירה!" |
| 36–41 | כרטיס סיום: הלוגו, המשפט והקישור |

## איך זה בנוי

הכל נבנה מהמשחק עצמו, בלי הקלטת מסך:

- **`vendor/`**: נבנה מהאתר החי ע"י `tools/build_vendor.py`. כולל:
  - הסטיילשיט והפונטים של המשחק (Rubik ו־Karantina)
  - מחולל הדמויות שלו (כל ירק, כל הבעה, וקטורי)
  - מסכים שצולמו ממצב ההדגמה של המשחק (`?demo=lobby`, `?demo=answer` וכו')

  `tools/lab.html` מציג כל מסך לצד הצילום המקורי לבדיקה.
- **`comp.html` + `film.js`**: הסרט כולו. `__seek(t)` מצייר כל פריים כפונקציה טהורה של הזמן.
  - מצלמה אחת (`motion.js` מסקיל onetake) מתחת לרכיבים האמיתיים של המשחק.
  - הקפיצים הם הקפיצים של המשחק עצמו (pop / soft / bouncy).
  - כל מעבר נושא משהו מהשלב הקודם: הכפתור נהיה תיבות, האווטארים צוללים לכרטיסים, הכרטיסים מתהפכים לכרטיסי הצבעה, ומהאווטאר נפתח הזרקור.
  - כל הזמנים בטבלה `T` אחת.
- **`audio/score.py`**: פס הקול. התזמונים מגיעים מהתמונה (`window.__events()` ← `tools/dump_events.py` ← `audio/events.json`).
  - **מקורות:**
    - הסאונדים של המשחק עצמו (`audio/game/`)
    - אפקטים מ־ElevenLabs (`audio/src/eleven/`, ההנחיות ב־`audio/sfx_nodes.json`)
    - טרק אינסטרומנטלי מקורי (ElevenLabs Music v2.5 דרך Higgsfield, ‏`audio/src/music/`), חתוך על גריד הביטים שלו
  - הכל בחדר אחד משותף, ומאסטר ל־‎−16 LUFS / ‎−4 dBTP.

## לבנות מחדש

```sh
python3 tools/build_vendor.py                 # רק אם המשחק השתנה (צריך גישה ל-hashtul.onrender.com)
python3 tools/dump_events.py                  # זמני הסאונד מהסרט
python3 audio/score.py                        # → audio/mix.wav
python3 tools/render.py comp.html --out out/draft.mp4 --sfx audio/mix.wav --width 1080 --height 1920 --grain 2.5           # טיוטה 30fps
python3 tools/render.py comp.html --out hashtul.mp4 --sfx audio/mix.wav --width 1080 --height 1920 --fps 60 --grain 2.5    # סופי 60fps

# הגרסה הנקייה (?cut=clean). פס קול משלה, כי אין בה את הקליק של מתג הפלפל:
python3 tools/dump_events.py cut=clean audio/events_clean.json
python3 audio/score.py audio/events_clean.json audio/mix_clean.wav
python3 tools/render.py "comp.html?cut=clean" --out out/clean/hashtul-clean.mp4 --sfx audio/mix_clean.wav --width 1080 --height 1920 --fps 60 --grain 2.5
python3 tools/stills.py out/stills.png 2.6,13.9,18.95,28.6,38.8   # דף מגע של רגעים
```

תצוגה מקדימה בדפדפן: `comp.html?play` (בזמן אמת) או `comp.html?t=18.95&hud` (פריים בודד). מוסיפים `&cut=clean` כדי לראות את הגרסה הנקייה.

`tools/render.py`, `tools/probe.py` ו־`tools/verify_promo.py` הם עותקים של הסקריפטים של onetake עם תיקונים לפורמט אנכי, ועם `--grain`: גרעין קל בקידוד במקום שכבת רעש בדף, שהאטה כל צילום פי 2.4.
