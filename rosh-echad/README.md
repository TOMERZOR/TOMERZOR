# ראש אחד: אב-טיפוס

משחק מילים יומי. כל יום יש שאלה אחת לכולם ("משהו שלוקחים לים"), וכל שחקן כותב עד 5 תשובות. כל תשובה שווה נקודות לפי אחוז האנשים שענו אותו דבר. בסוף יש שורת אימוג'י לשיתוף בוואטסאפ, בלי לחשוף את התשובות.

- `prototype/index.html`: המשחק כולו בקובץ אחד (HTML, CSS ו-JS, בלי שרת).

## מה עובד

- שאלה יומית שמתחלפת בחצות. שאלה #1 היא מ-28.10.2026, ויש 8 שאלות שחוזרות במחזור.
- זיהוי תשובות גמיש: מתעלם מה' הידיעה, מאותיות סופיות, מניקוד ומסימני פיסוק, מקבל שגיאת כתיב של אות אחת, וכל תשובה יכולה להיכתב בכמה דרכים.
- מסך תוצאות: ניקוד, דירוג ("ישראלי מצוי", "רגל אחת בברלין"...), טבלת תשובות הקהל, טקסט לשיתוף, ספירה לאחור לשאלה הבאה, רצף ימים.
- "עוד שאלות לתרגול": אפשר לשחק את כל השאלות, בשביל בדיקות.

## מה עוד לא אמיתי

- **התשובות של הקהל הן הערכה שכתבתי מראש**, לא תשובות של שחקנים. בשביל הגרסה האמיתית צריך שרת שאוסף תשובות, מאחד תשובות דומות (AI עושה את זה טוב) ומפרסם את התוצאות למחרת.
- התוצאות נשמרות רק בדפדפן של כל שחקן (localStorage).

## להוסיף או לשנות שאלה

ברשימה `QUESTIONS` בתוך `prototype/index.html`. כל תשובה היא `[תווית, אחוז, [דרכים אחרות לכתוב אותה]]`.
