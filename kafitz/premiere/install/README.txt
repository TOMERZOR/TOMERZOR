קפיץ לפרימייר (Kafitz for Premiere Pro)
=======================================

התקנה
-----
Mac:      לחיצה כפולה על install/install-mac.command
          (אם macOS חוסם: קליק ימני > Open > Open)
Windows:  לחיצה כפולה על install\install-windows.bat

אחרי ההתקנה: לסגור ולפתוח את Premiere Pro, ואז
Window > Extensions > Kafitz · כתוביות

עבודה
-----
1. פותחים סיקוונס. מסמנים את הקליפים עם הדיבור (בלי סימון: כל מה שעל A1).
2. "תמלול הסיקוונס". בפעם הראשונה מנוע התמלול יורד (דרוש אינטרנט), אחר כך הוא שמור.
3. משחקים עם העיצוב והטקסט. התצוגה עוקבת אחרי הסמן של פרימייר.
4. "הוספה לטיימליין": הכתוביות נשמרות כרצף תמונות PNG שקוף בתיקייה
   "Kafitz Captions" ליד קובץ הפרויקט, ונכנסות לערוץ וידאו פנוי מעל הקליפים.
   לחיצה נוספת אחרי שינויים מחליפה את הגרסה הקודמת בטיימליין.
5. "כתוביות פרימייר": ערוץ כתוביות רגיל של פרימייר (בלי אנימציה), לעריכה בתוך פרימייר.

דרישות: Premiere Pro 2021 (15.0) ומעלה.
